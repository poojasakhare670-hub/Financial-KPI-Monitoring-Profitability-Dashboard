# Financial KPI Monitoring & Profitability Dashboard

## Project Overview
A Power BI dashboard developed to monitor financial KPIs, profitability, revenue performance, budget variance, and business performance.

## Objectives
- Monitor key financial KPIs
- Analyze revenue and profitability
- Compare actual revenue with budgeted revenue
- Identify budget variances
- Analyze performance by region, department, product category, and sales channel

## Key KPIs
- **Total Revenue:** $6.96M
- **Total COGS:** $3.15M
- **Gross Profit:** $3.81M
- **Net Profit:** $2.61M
- **Net Profit Margin:** 37.4%

## Dashboard Features
- Revenue trend analysis
- Actual vs Budgeted Revenue
- Budget Variance analysis
- Gross Profit and Net Profit by Department
- Operating Expenses by Department
- Revenue by Region
- Net Profit by Product Category
- Revenue by Sales Channel
- Financial Waterfall Analysis
- Month and Department filters

## Tools Used
- Power BI
- Microsoft Excel
- DAX
- Data Visualization
- Business Analysis

## Files Included
- **Power BI Dashboard:** `_Financial KPI Monitoring & Profitability Dashboard.pbix`
- **Business Analysis Report:** `Financial_KPI_Business_Analysis_Report.docx`
- **Dataset:** `Financial_KPI_Monitoring_Dashboard_Dataset.xlsx`

## Key Insights
The dashboard provides a consolidated view of financial performance and highlights revenue trends, profitability patterns, budget gaps, regional performance, product-category performance, and sales-channel contribution.

## Project Outcome
The dashboard enables management-oriented monitoring of financial performance and supports identification of areas requiring attention based on profitability and budget performance.
